端到端

解决三个挑战：
1. 用户兴趣建模和商业价值优化之间的目标不一致
2. 生成过程天然存在的目标感知不足问题
3. 生成阶段与排序阶段之间的表示割裂问题

框架由三个步骤组成：
1. 生成阶段
2. 多任务/目标感知阶段
3. 排序阶段

##### 生成增强：多目标任务感知增强

统一的、可学习的任务token序列，在架构层面实现兴趣建模与业务价值优化的解耦，而不是将多种目标混合在单头表示空间中进行建模。

该序列采用随机初始化，并在训练过程中进行端到端优化，有两类token，
兴趣任务token：用于建模差异化的兴趣维度，并通过独立预测头捕获多兴趣分布。每个 token 可以对应一个独立的兴趣目标或业务任务，也可以共同组成一个顺序任务链（例如：曝光 → 点击 → 转化）
价值感知任务token：专门用于学习业务价值

所有 token 共享底层用户表征，但通过独立的输出头实现任务空间的解耦，从根本上缓解了兴趣覆盖与价值优化之间的内在张力。每个任务 token 位置上的输出都会被送入一个独立的预测头，从而实现多任务的显式解耦与并行学习。

  
为了建模任务之间的依赖关系，我们提出了**任务顺序先验与因果掩码（causal mask）的协同机制**：

我们引入任务顺序先验，按照业务流程和认知难度对任务进行排序（例如：曝光 → 点击 → 转化 → 业务价值）；同时施加因果掩码，使后续任务能够访问前序任务的表征，从而在任务之间实现知识迁移与逐步细化。

##### 虚拟物品token(Fake Item Token)：粗粒度目标感知

这些token是通过在整个物品空间上执行K-means聚类所得到的k个聚类中心向量，代表了物品语义空间中的核心锚点

##### 异构注意力解码器

Step 1 的输出作为解码器的 Key/Value，而 Query 输入来自构建的任务 token 和虚拟物品 token

两个关键改进：
1. Cross-attention前置：传统解码器通常先执行 Self-Attention，再执行 Cross-Attention；而我们将这一顺序反转。**动机：首先通过 Cross-Attention 对用户的多兴趣表征（即来自 Step 1 的 Key/Value）进行聚合与总结，以获得充分的用户—物品交互信息；随后，再通过 Self-Attention 对聚合后的 Query（Task + Fake Item）进行内部整合和任务间协同建模。**
2. 异构mask策略：一种细粒度的mask机制
	1. task tokens之间：施加 causal mask，以保证任务序列中的时序建模和依赖关系捕获；
	2. 从 Task Tokens 到 Fake Item Tokens：每个 Task Token 都可以访问全部 Fake Items，从而实现隐式的目标感知交互；
	3. 从 Fake Item Tokens 到 Task Tokens：每个 Fake Item 都可以访问全部 Task Tokens，以充分捕获多任务语义；
	4. Fake Item Tokens 之间：彼此不可见，以避免不同聚类中心之间相互干扰，确保每个 Fake Item 都能够独立地与用户意图进行“探索式”匹配。

##### 双通道表征构建

任务语义通道：每个task token提供一个语义向量，用于编码该任务维度下的深层语义表征。

目标感知通道：对当前任务，把当前task token和每一个fake item token拼接起来，送入一个MLP，得到一个分数向量
对所有 fake item 都做完之后，再把这些结果聚合起来，得到：目标感知表示，即**用户在任务** i **下，对整个物品语义空间各个区域的偏好分布。**
k个fake item tokens：理解为整个物品空间里的k个语义原型/聚类中心

### 统一排序

设计了一个专用的排序解码器：R-Decoder Block，将排序过程内化为生成流程的自然延伸，而不是作为一个外部的后处理模块。

输入设计：R-Decoder的Query由两部分组成：
1. 一个专用的排序任务token
2. 来自Step2中多路径生成结果（MTP）的n个候选物品token，表示待排序的候选集合
key和value则融合了Step1中原始的多兴趣表征与Step2中精细化后的表征

Mask策略：候选物品token彼此之间不可见，以避免候选之间相互干扰，并确保每个候选的打分独立性；所有候选物品token都可以访问排序任务token

输入侧一致性：**Key/Value贯通机制**：Step 3 中的排序解码器直接复用 Step 1 和 Step 2 的输出作为 Key/Value，从而实现高效、低成本的信息流连通。

输出侧一致性与优化目标：输出侧一致性通过一个**三元联合损失函数**来对齐生成与排序的优化目标，从而实现端到端协同优化。
a生成损失+b排序损失+c分布一致性损失（对齐生成分布与排序分布）
