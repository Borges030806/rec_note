1. **处理不确定模态缺失**
    
    - 能够在 **训练和测试阶段** 同时应对任意模态缺失或部分缺失的情况（例如音频、视频或文本可能缺失或异常）。
        
    - 不需要为每种缺失模式训练单独模型，而是通过共享子空间统一处理各种缺失情况，提高适用性和可扩展性。
2. **重建缺失模态**
    
    - 利用共享子空间和 Transformer 进行信息交互，可以 **重建任何缺失模态** 的特征。
        
    - 重建过程中保留多模态的共同信息，确保生成的特征尽可能接近真实模态。
3. **提升多模态联合表示的鲁棒性**
    
    - 无论是否有缺失模态，模型都能生成统一的联合表示，用于下游任务（如情感分析、分类或回归）。
        
    - 对少量完整模态样本或存在噪声、异常的模态数据也具有较好的鲁棒性。


 各模态特征 → 单模态编码（统一维度 + Transformer）
    
投影到共享子空间 → 拼接降维 → Transformer交互 → 重建缺失模态
    
 所有模态（可用 + 重建） → 交叉模态注意力 → 联合表示
    
联合表示 → 下游任务预测（分类/回归）
    
训练中使用重建损失 + 任务损失 + 数据增强 + 迭代优化


缺点：RMRU 对整个模态缺失鲁棒，但对于模态内部不连续缺失，需要额外预处理或专门机制来保证性能；依赖重构需要的源模态，如果源模态有噪声，则表现不足。
